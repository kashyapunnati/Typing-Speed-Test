# ⌨️ Typing Speed Test

## 📖 Description

This project is a responsive Typing Speed Test developed using HTML5, CSS3, and JavaScript.

The application displays a random passage and allows users to type it while measuring their typing speed and accuracy.

Users can also restart the current test or choose another random passage for a new test.

## ✨ Features

- 📝 Random passage display
- 🔀 Another Passage option
- ⌨️ Live typing
- 🟢 Correct character highlighting
- 🔴 Incorrect character highlighting
- ⏱️ Timer starts on the first keystroke
- 📊 Words Per Minute (WPM) calculation
- 🎯 Accuracy calculation
- 🔄 Restart functionality
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Date Object
- Event Listeners
